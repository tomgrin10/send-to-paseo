Send to Paseo's button now carries Paseo's mark and shows what the PR's workspace is doing, so you can see when it needs you without opening anything.

### New

- The Send to Paseo button on GitHub and Graphite shows Paseo's mark instead of the paper plane.
- The button shows the PR's workspace state. A small blue dot means an agent is working, and an × means Paseo can't be reached or isn't set up yet. When it's your turn, a short word appears beside it: "Asks you", "Conflict", "Merge ready", "Agent closed" (needs the newest Follow-up) or how many need you.
- Hover or focus the button to see the full state, the workspace and the machine it's on. The state refreshes when you come back to the tab and after you send.
- "Workspace for this PR" in the popover is led by Follow-up's icon when Follow-up information is shown.

### Fixed

- Workspaces Follow-up lists as Sending now sort with active work in the popover and show the working color, instead of last and grey.
- The button uses the state colors Follow-up chooses. With an older Follow-up it still shows a dot, colored from the workspace's group.
