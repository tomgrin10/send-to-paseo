Send to Paseo

Pairs this extension with the send-to-paseo Paseo plugin's local bridge — on as many Paseo machines as you run one on.

Paseo hosts

Every pull request is resolved on all enabled hosts at once, and the composer shows the workspaces each one has. Each host needs its own pairing token: tokens belong to a plugin install and are not interchangeable.
A bridge on another machine binds 127.0.0.1 there, so reach it through a loopback tunnel — ssh -L 7789:127.0.0.1:7788 devbox — and give this host http://127.0.0.1:7789.
