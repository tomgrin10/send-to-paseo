Send to Paseo

The browser connects to one Primary Paseo machine. That machine can route sends to your other Paseo machines without giving Chrome more network permissions.

Simple setup

Browser machine → Primary Paseo machine Recommended. The extension always uses http://127.0.0.1:7788. Add dev VMs and other machines inside the Send to Paseo plugin on the Primary Paseo machine.

Primary Paseo machine

Copy the pairing token from Paseo on this browser machine. No Tailscale command, SSH tunnel, remote URL, or Chrome permission is needed here.
Saved
Advanced: connect the browser directly to each Paseo machine
Use this only when you do not want the Primary Paseo machine to route requests. Every additional machine needs its own HTTPS private bridge address, pairing token, and exact Chrome site permission. Existing multi-machine setups remain here and keep working.
